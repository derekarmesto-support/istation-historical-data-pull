Istation Historical Data Pull

Download historical Istation reports for any district — directly from your browser, no manual portal navigation required.

📅 2018-19 through 2024-25
🌐 secure.istation.com
💻 Mac + Windows
What this tool does

When a district requests historical data, this tool logs into Istation using your Google account and downloads the requested CSV exports automatically. You fill out a short form, click Start Download, sign in once, and the files land on your computer.

Executive Summary
Student-level ISIP assessment results by skill and period
Usage
Minutes spent per student across the school year
Usage Trend
Week-by-week usage over time
Level Movement
Students who moved up or down a reading/math level
Completion
ISIP assessment completion rates by student
How to get started
1
Set up the tool on your computer

Follow the setup guide for your operating system. Takes about 10–15 minutes and only needs to be done once.

2
Launch the dashboard

Open Terminal (Mac) or Command Prompt (Windows) and run the start command. The dashboard opens in Chrome.

3
Use the Reports tab

Enter the district OID, select years and report types, and click Start Download. Chrome will open, you'll sign in once, and files download automatically.

Installation — macOS

Mac Setup

Takes about 10 minutes. Only needs to be done once.

What you need
Python 3
3.9 or later
Most Macs already have this
Google Chrome
latest
Must be up to date
Homebrew
any
Free — install in Step 2
Amira Google Account
@amiralearning.com
Needs Istation admin access
Steps
1
Open Terminal

Press ⌘ Space, type Terminal, press Enter.

2
Check if Python is installed
SKIP IF INSTALLED Run this first
Terminal
% python3 --version
Python 3.12.0 ← if you see this, skip to Step 3

If you don't see a version number, install Python from python.org/downloads — download the latest macOS installer and run it.

3
Check if Homebrew is installed
SKIP IF INSTALLED Run this first
Terminal
% brew --version
Homebrew 4.x.x ← if you see this, skip to Step 4

If you don't see a version, install Homebrew:

Terminal
% /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
==> Homebrew installed successfully
ℹ
It will ask for your Mac password. Nothing appears as you type — that's normal. Press Enter when done.
4
Install ChromeDriver Required

ChromeDriver lets Python control Chrome to log in to Istation automatically. Most people won't have this — run both commands.

Terminal
% brew install --cask chromedriver
🍺 chromedriver was successfully installed

% xattr -d com.apple.quarantine $(which chromedriver)
✓
The second command has no output when it works. If you see "No such xattr" — that's fine, keep going.
5
Install Python packages Required

Installs Streamlit (the dashboard), Selenium (browser automation), and Requests (file downloads).

Terminal
% pip3 install streamlit selenium requests
Successfully installed streamlit selenium requests
6
Check if Git is installed
SKIP IF INSTALLED Run this first
Terminal
% git --version
git version 2.x.x ← if you see this, skip to Step 7

If Git isn't installed, macOS will prompt you to install the Xcode Command Line Tools — click Install and wait for it to finish.

7
Download the project Required
Terminal
% cd ~/Documents
% git clone https://github.com/derekarmesto-support/istation-historical-data-pull.git
Cloning into 'istation-historical-data-pull'...
8
Start the dashboard
Terminal
% cd ~/Documents/istation-historical-data-pull
% streamlit run istation_dashboard.py --server.port 8503

You can now view your Streamlit app in your browser.
Local URL: http://localhost:8503
ℹ
Chrome will open automatically. If it doesn't, go to http://localhost:8503.
⚠
If you see "Port 8503 is not available": lsof -nP -iTCP:8503 | awk 'NR>1{print $2}' | xargs kill -9 then try again.
9
Confirm it's working
✓
You should see three tabs: Request Sheet, Historical Run, and Reports.
🚀

Setup complete

Head to the "Using the Reports Tab" guide to run your first download.

Stopping the dashboard

Go back to Terminal and press Control + C. Don't close Terminal while a download is in progress.

Advanced Options

Click Advanced Options to access additional filters. These are optional and rarely needed for standard requests.

Grade Filter
Limit results to a specific grade level. Default is All.
Skill Filter
Filter by a specific skill area within a product.
Assessment Mode
Year to Date (default), Current Month, or specific periods.
Save Location
Where files are saved. Defaults to your Documents folder.
Common issues
⚠
Start Download is greyed out — One or more required fields is empty. Check that email, district, school year, at least one product, and at least one report type are all filled in.
⚠
Chrome opens but stays on the login page — Complete the Google sign-in manually. The tool will resume downloading automatically after login.
⚠
A file shows ⚠ no data returned — Istation returned an empty export for that product/year combination. This is a data issue on Istation's side, not a tool error.
